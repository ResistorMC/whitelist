# Whitelist
Плагин белого списка для майнкрафт-серверов на Paper с автоматической очисткой неактивных игроков.

Игрока на сервер пускает, только если он есть в белом списке. Если игрок долго не заходит, то плагин
сам убирает его из вайтлиста.

Плагин создан для небольших ванильных серверов, с дополнительными защитными плагинами по типу AuthMe.

## Возможности
- Проверка ника игрока при входе из кэша.
- Хранение белого списка в SQLite.
- Автоматическое удаление игроков, которые не заходили дольше заданного срока.
- Возможность выдать рест.
- Практически все сообщения настраиваются в config.yml.

## Требования
- Paper 1.21.x
- Java 21
- Paper. Spigot и другие форки без Paper не поддерживаются, плагин использует
  Adventure и MiniMessage.

## Установка
1. Скачайте .jar файл из Releases.
2. Положите файл плагина в папку plugins сервера.
3. Запустите сервер.
4. Добавьте игроков командой `/wh add <nick>`.

> Если плагин не смог загрузить базу данных или таблицу при запуске, он останавливает сервер.

## Команды
Все команды доступны с правом whitelist.manage (default: op).

| Команда | Что делает |
|---------|------------|
| `/wh add <nick>` | добавляет игрока в белый список |
| `/wh del <nick>` | убирает игрока из белого списка |
| `/wh info <nick>` | выводит информацию об игроке: последняя активность, рест |
| `/wh list <страница>` | выводит список ников, находящихся в белом списке |
| `/wh rest <nick> <дни>` | выдает рест указанному игроку на указанное кол-во дней | 
| `/wh rest <nick> cancel` | отменяет рест игроку |
| `/wh reload` | перезагружает конфиг |

Ник: 3-16 символов, только латинские буквы, цифры и _. Регистр не важен, плагин всё переводит в нижний.

## Сообщения (конфиг)
Цвета в тексте сообщения задаются в формате MiniMessage (https://docs.advntr.dev/minimessage/format.html): теги вида `<green>` `</green>`, `<#ffffff>` `</#ffffff>`.
В некоторых сообщениях доступны подстановки: `<nick>`, `<day>`. Лучше берите сообщение в кавычки.

## Как работает очистка неактивных
1. Плагин записывает время последнего захода игрока (при входе и выходе).
2. Первая проверка выполняется через 30 секунд после запуска сервера, дальше раз в указанное в конфиге количество минут.
3. Из белого списка убираются игроки, которые:
    - сейчас не в сети;
    - не находятся в ресте;
    - не заходили дольше количества дней, установленного в конфиге.
4. Когда рест заканчивается, срок неактивности отсчитывается заново.

> Новый игрок, добавленный командой, считается только что заходившим.

## Предупреждения
- Проверка идёт по нику, а не по UUID. На серверах с online-mode=false любой сможет зайти под чужим ником,
  поэтому для таких серверов рекомендуется плагин авторизации (например, AuthMe).
- Плагин поддерживает только SQLite.
- Запись в базу данных идёт из основного потока сервера. На небольших серверах это будет незаметно.
